# Task: Результаты кейса как артефакты агентов (Фаза 1.5) — убрать «итог = schedule.inc»

Read first: `AGENTS.md` (весь), `MAS_REFACTORING_PLAN.md` §2.5, §3 п.9–10, §4 «Фаза 1.5»; правила `.cursor/rules/mas-activity-service.mdc`, `n8n-templates.mdc`, `live-harness.mdc`.

## Goal

Сегодня UI, Activity, оркестратор и харнесс считают файл `schedule.inc` итогом всей работы кейса. Заказчик решил: SCHEDULE — промежуточный этап более длинной цепи (файлы модели на кластере → запуск tNavigator через CLI → мониторинг расчёта → выгрузка из бинарных результатов). Результат кейса — **набор deliverables, произведённых агентами**. Каждый артефакт — карточка `{artifact_id, role, kind: input|intermediate|deliverable, producer: user|<agent_id>, filename, mime, bytes, summary, created_at}`. UI показывает deliverables у сообщения агента, который их сделал, и в панели «Результаты» по агентам; `case.finished` — итог оркестратора по агентам со списком deliverables. Ни UI, ни Activity, ни `planner_input` не знают слова `schedule_out` как названия «результата».

Цитата плана (Фаза 1.5): «Сделав это до Фазы 2, убираем `has_schedule_out` и слоты одним движением — Фаза 2 (универсальный `MERGE`, `state.agents[<id>]`) станет короче.»

## Out of scope

- Промпт оркестратора (`SYSTEM`), `ROUTE`, bucket'ы `data.excel/schedule` в `MERGE` — это Фаза 2. Менять только артефакты и `planner_input.deliverables`.
- Контракт агентов не меняется: Schedule Builder продолжает возвращать `artifacts: {schedule_out: <text>, diff: <text>}`; Excel — `data.excel`. `producer`/`kind` ставит оркестратор при слиянии.
- Долгие агенты / статус `in_progress` / внешний `resume` — Фаза 1.3, не трогать.
- `n8n/templates/retired/`, `n8n/workflows/retired/`, goldens `*_MAS_result.INC`, wipe кейсов — нет.
- Excel Tools и Schedule Builder (Python) — не трогать, кроме тестов, если они читают `state.artifacts` по старым слотам (проверить `excel-agent-tools/app/agent_run.py` `_walk_excel_cards`, `schedule-builder-service/app/agent_tools.py` `open_session` — они должны продолжать находить `excel`/`excel_N`/`schedule_source_N` по `artifact_id`/`role`).
